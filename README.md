# 차곡 · Daylog

React 기반 데스크톱 우선 개인 일정·장소 기록 웹앱입니다.

## 실행

현재 PC에서는 `start.cmd`를 실행하고 http://127.0.0.1:5173 에 접속하세요. 의존성 설치는 완료되어 있습니다.

```sh
npm install
npm run dev
```

빌드: `npm run build`. 배포용 파일은 `dist/`에 생성됩니다.

## 구현된 기능

- 다크 테마 3열 대시보드, 전체 텍스트 검색
- 월간 캘린더, 주간·일간 목록, 날짜 선택, 드래그 날짜 이동
- 일정·할 일 생성/수정/삭제/복제, 우선순위, 태그, 색상, 하위 체크리스트
- 할 일 완료 시 다음 반복 회차 생성, 4분면, 정렬, 일괄 완료, 밀린 일 이동
- 자연어 빠른 입력: 오늘/내일/모레 및 오전/오후 시간
- 일기, 감정, 이미지 압축 업로드, 장소 기록 타임라인
- OpenStreetMap 지도, 지도 클릭으로 좌표 선택, 장소 검색, 현재 위치
- 여행 생성/수정/삭제, 여행별 장소 필터, 재방문 즐겨찾기, 별점, 동행인
- 북마크 및 외부 링크 열기
- Open-Meteo 실시간 5일 날씨 (서울/부산/제주)
- localStorage 저장, JSON 전체 백업 및 추가 병합 복원
- ICS 기본 일정 가져오기/내보내기
- 모바일 반응형 화면
- 사진 없이 여백·타이포·색면으로 구성한 밝은 편집형 대시보드

## 범위 및 제한

이 버전은 서버 없는 로컬 앱입니다. 계정 로그인, 사용자 간 실시간 공동 편집, OAuth 캘린더/Google Tasks 동기화, 푸시 알림, 운영체제 위젯·잠금화면은 연결되지 않았으며, 설정 화면에도 표시됩니다. ICS 가져오기는 기본 제목·날짜·시간에 한하며, 시간대 변환·반복 규칙 가져오기는 지원하지 않습니다. 반복 일정은 생성 시 12회가 만들어지고, 수정·삭제는 선택한 회차에 적용됩니다. 장소·날씨·지도에는 인터넷 연결이 필요합니다. 사진은 브라우저 저장 공간을 사용하므로 정기 백업을 권장합니다. 서비스는 비공개 개인 공간으로 동작하며 실제 위치 추적은 하지 않습니다.

기본 예시 데이터는 메인 상단의 ‘예시 비우고 시작’으로 제거할 수 있습니다.

## 검증

- Vite 프로덕션 빌드 통과.
- 실제 브라우저에서 자연어 `내일 오후 3시 기능 확인` → 다음 날 15:00 할 일 저장 확인.
- 지도 클릭 → 소수 좌표 자동 입력 → 장소명 및 메모 저장 확인.
- 새로고침 후 할 일 및 장소 기록 유지 확인.
- 지도 타일과 실시간 날씨 응답 확인.
- 입력 중 컴포넌트 재생성으로 포커스가 해제되는 문제 수정.
